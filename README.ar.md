# سكيلات GoharyAI — مونتاج فيديو بكلود كود

خمس سكيلات لـ [كلود كود](https://claude.com/claude-code) بتحوّل كلود لمونتير فيديو: تديه فيديو خام وإنت بتتكلم للكاميرا، أو فولدر هوكات وتسجيلات شاشة، أو سكربت، أو ريل مرجعي، أو فكرة بوست، ويرجّعلك ملفات جاهزة بهويتك، بصوت مضبوط. كل حاجة بتترندر على جهازك بـ **ffmpeg + كروم + بايثون**، من غير برنامج مونتاج ولا اشتراكات.

[English](README.md) · من **أحمد فاروق جوهري** · [@goharyai](https://instagram.com/goharyai)

| السكيل | بتديه | بياخد منه |
|---|---|---|
| **goharyai-reel** | فيديو كلام للكاميرا | يشيل السكتات، كابشن بتوقيت الكلمة (عربي/إنجليزي)، كروت موشن بالهوية، زوم، موسيقى أصلية، مؤثرات، كرت نهاية، وتقرير فحص — 9:16 أو 16:9 |
| **goharyai-hook-ads** | فولدر هوكات + شروح شاشة + موسيقى | كل هوك مع كل شرح في إعلان منفصل بكابشن لكل خطوة (4 × 4 = 16 نسخة) بأمر واحد |
| **goharyai-motion** | سكربت أو فكرة | فيديو موشن من غير كاميرا: نص متحرك، عدادات، قوائم، كتابة في التيرمينال، سكرينشوتات، تعليق صوتي، موسيقى |
| **goharyai-clone** | ريل مرجعي عاجبك | تحليل بالأرقام (القطعات، الإيقاع، مقاسات الخطوط)، مسارين (فكرة أصلية / استنساخ احترافي)، بناء بمحتواك، ولوحة مقارنة بالأصل |
| **goharyai-covers** | عنوان أو بوست | كفر ريل، 3 أفكار ثمبنيل، كاروسيل إنستجرام/لينكدإن، قص الخلفية |

الخمسة بيشتركوا في **goharyai-core**: الهوية، الخطوط، الرندر، التفريغ، الصوت، الكابشن، الموسيقى، المكس، والفحص. غيّر `brand.json` واللوجو وكل المخرجات تبقى بهويتك إنت.

## التثبيت
```bash
git clone https://github.com/Farouk1901/goharyai-skills
cd goharyai-skills
./install.sh            # ماك / لينكس
.\install.ps1           # ويندوز باورشيل
```
المثبّت بينسخ السكيلات لـ `~/.claude/skills/`، وبيعمل `npm install` للرندر، وبيطبع فحص البيئة. المطلوب:
- **ffmpeg** و **ffprobe**
- **Node.js 18+** ومتصفح كروميوم (كروم أو إيدج أو بريف)
- **بايثون 3.10+** مع `pip install faster-whisper numpy soundfile pillow`
- اختياري: `pip install kokoro soundfile` (تعليق صوتي إنجليزي بدون إنترنت، بايثون ≤ 3.12)، و`pip install rembg onnxruntime` (قص الخلفية)

وبعدها في كلود كود: *"منتج الفيديو ده ريل"* — أو `/goharyai-reel`.
